# Java runtime components

- Gson 2.13.2, Apache-2.0, https://github.com/google/gson
- Nimbus JOSE + JWT 10.10, Apache-2.0, https://connect2id.com/products/nimbus-jose-jwt
- Error Prone annotations 2.41.0 (Gson dependency), Apache-2.0, https://github.com/google/error-prone
- Bouncy Castle bcprov, bcpkix and bcutil 1.86, see retained individual license files.

The Apache-2.0 text is included in this directory. The upstream Maven artifacts for Gson and Nimbus do not contain a separate copyright notice file. The OpenJDK runtime retains its own legal/ directory, including GPL-2.0 and Classpath Exception notices. Build-time JUnit components are not included in the runtime JAR.
