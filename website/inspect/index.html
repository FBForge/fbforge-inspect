VERSION 0.2.0

Öffentliche Konfiguration.
Nachvollziehbare Befunde.

FBForge Inspect unterstützt Entwickler und Integratoren, die die Konfiguration von FIT-Connect-Zustellpunkten und die Ergebnisse öffentlicher Routing-Abfragen nachvollziehen möchten. Die Windows-App bringt ihre Java-Laufzeit mit. Das portable CLI führt öffentliche Prüfaufträge auch auf Windows Server und Linux mit Java 25 oder neuer aus.

Fachdatenschemata sind bei der jeweiligen Leistung im FIT-Connect-Zustellpunkt hinterlegt. Aus PVOG stammen Adressierungssignaturen (Destination Signatures) und gegebenenfalls EfA-Parameter.

Die folgenden Bilder zeigen Browseraufnahmen mit fiktiven lokalen Beispielen. Eine Diagnose ist keine Gesamtfreigabe der Integration. Automatisierte Prüfungen ersetzen keine vollständige Barrierefreiheitsabnahme.

DIAGNOSE MIT QUELLENNACHWEIS

Von einer ID zum
nächsten sinnvollen Schritt.

01 / DESTINATION

Konfiguration verstehen

V2 und V3 vergleichen. Leistungen, Regionen und zugehörige Fachdatenschemata im FIT-Connect-Zustellpunkt prüfen.

02 / ROUTING

Öffentliche Wege sehen

LeiKa und Gebiet abfragen. Routing-Ergebnisse und PVOG-Adressierungssignaturen getrennt nachvollziehen.

03 / SCHLÜSSEL

Nachweise unterscheiden

JWK, Zertifikate, PKIX und signierte OCSP-/CRL-Antworten prüfen. Unbekannter Status bleibt erkennbar.

04 / PROZESSE

V3 gezielt erproben

Öffentliche Prozesssuche anhand von Modell, Nachricht und Region. Paarbezogene Limits direkt anzeigen.

05 / SCHEMATA

Strukturen lesen

JSON Schema und XSD lokal oder per öffentlichem Abruf untersuchen. Referenzen bewusst einzeln öffnen.

06 / BERICHTE

Befunde weitergeben

Eigenständige HTML- und JSON-Berichte mit Vorschau lokal speichern. Rohantworten nur nach Auswahl.

07 / SAMMELPRÜFUNG

Gezielt und kontrolliert prüfen

Bis zu 32 Prüfungen vorbereiten, nacheinander starten, pausieren und einzelne offene Einträge wiederholen. Aufträge ausdrücklich speichern und öffnen.

08 / SERVERDIAGNOSE

Am richtigen Ort messen

Das Java-CLI aus der App exportieren oder als eigenes Releasearchiv laden. Auf Windows und Linux ausführen. Ergebnisdatei und Rückgabecode anschließend in Inspect auswerten.

09 / NETZWERK UND TLS

Den Verbindungsweg erklären

DNS, TCP, Proxy, TLS und HTTP getrennt betrachten. Öffentliche HTTPS-Unternehmens-CAs ausdrücklich ergänzen und betroffene Ziele einzeln erneut prüfen.

10 / ZERTIFIKATSINVENTAR

Betroffene Stellen überblicken

Untersuchte Teilnehmerzertifikate nach Fingerabdruck gruppieren, Zustellpunkte zuordnen und Erneuerungstermine exportieren. Öffentliche Ersatzschlüssel gezielt prüfen.

11 / ANALYSEWERKZEUGE

Zusammenhänge verfolgen

Bekannte Zustellpunkte rückwärts prüfen. Öffentliche Zertifikate und Adressierungssignaturen separat untersuchen. Eingefügte Kennungen und URLs vor der Übernahme ansehen.

12 / HILFE UND UPDATES

Im Arbeitsablauf bleiben

Offline-Hilfe durchsuchen und Supporttexte mit Vorschau vorbereiten. Neue stabile Windows-Versionen ausdrücklich suchen und vor der Installation auf ihre Signatur prüfen.

AUF IHREM GERÄT

Ohne Konto.
Mit nachvollziehbaren Grenzen.

FBForge Inspect führt öffentliche Leseabfragen aus. Es benötigt keine FIT-Connect-Zugangsdaten und keinen gehosteten Dienst. Keine Telemetrie. Prüfstände bleiben ohne ausdrücklichen Export im Sitzungsspeicher.

Die App ersetzt keine authentifizierten Integrationstests und erteilt keine Zertifizierung. STAGE-Routing, unvollständige Antworten und fehlende Sperrnachweise werden ausdrücklich gekennzeichnet.

Für Windows x64 mit WebView2. Java wird mit der App gebündelt. Den Installer und die zugehörigen Prüfsummen sowie das Java-CLI-Archiv für Windows und Linux finden Sie im GitHub-Release. Das CLI benötigt eine eigene Java-25-Laufzeit. Die EXE allein ist kein portables Paket.
